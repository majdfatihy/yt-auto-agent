# وكيل YouTube Reels — المرحلة الثالثة: كابشنز عربية داخل معاينة الفيديو

## نطاق التحديث

هذه الحزمة **تعديل محدود على المرحلة الثانية التي نجح اختبارها فعليًا**؛ ليست استبدالًا للمشروع كله.

**الملفات المرفقة فقط:**
- `agent.py` (معدل): بعد `/clip 1` أو اختيار عدة مقاطع، يتم استخراج التوقيتات من **صوت MP4 الأصلي** مرة واحدة لكل تشغيل، وحرق الكابشنز في الفيديو المقصوص، ثم إرسال النسخة التي تحتوي على النص.
- `transcription_pipeline.py` (معدل): إضافة اختيار التوقيتات على مستوى الكلمة في Groq **لمعاينة القص فقط**؛ لا تغيير للمسار الافتراضي المستخدم بواسطة `/prepare` و`/seo`. يتدرج إلى مزودي التفريغ الموجودين إذا تعذرت خدمة Groq.
- `captions_renderer.py` (جديد): تجهيز كابشنز عربية بصيغة ASS، مع تعويض بداية القص، وحدّ زمني لكل بطاقة، ونص بحد أقصى سطرين غالبًا، وخط `Noto Sans Arabic` وحد أسود للقراءة، ثم دمجها في MP4 باستخدام FFmpeg.
- `.github/workflows/main.yml` (معدل): إضافة `fonts-noto-core` و`fontconfig` لتوفير خط عربي حقيقي في GitHub Actions.
- `tests/test_stage3.py` (جديد): اختبارات تفريغ/توقيتات/حماية النصوص ومنع التسليم عند فشل الكابشنز.

**لم يتغير:** `worker.js`، ملفات Cloudflare، `clip_planner.py`، أسلوب اختيار المقاطع، `/prepare`، `/seo`، `/publish`، إعدادات GitHub Secrets، متغيرات Cloudflare، وسلوك عدم النشر. لا حاجة لتحديث Cloudflare Worker في هذه المرحلة.

## طريقة التطبيق — خطوة بخطوة

1. احتفظ بنسخة احتياطية من المشروع الحالي الناجح.
2. فك الضغط في **جذر مجلد `yt-auto-agent`** بنفس أسماء الملفات والمسارات ثم وافق على الاستبدال للملفات المحددة فقط.
3. افحص `git status` أو شاشة مراجعة `update_v5_fixed.bat` قبل الموافقة على أي رفع.
4. شغّل `update_v5_fixed.bat` وفق استخدامك السابق، ثم تحقق من نجاح GitHub Actions في إحدى محاولات الاختبار.
5. في تيليجرام استخدم `/clip 1` اعتمادًا على الاقتراحات المحفوظة. سيصل فيديو 1 بكابشنز ملتصقة بالصورة وليس مجرد وصف نصي. لا تستخدم `/publish`؛ النشر لا يزال محظورًا.

## الاختبارات المحلية المنفذة

- 21 اختبار Python ناجح (7 مرحلة أولى، 6 ثانية، 8 ثالثة).
- 6 سيناريوهات Cloudflare Worker القديمة ناجحة دون أي تعديل على Worker.
- FFmpeg تم اختباره على فيديو اختباري له صوت، وتأكدنا من وجود بكسلات جديدة للكابشنز في الصورة ومدة الفيديو سليمة.

**لم يُختبر تشغيل API فعلي ولا إرسال فيديو على تيليجرام من هذه البيئة.** النجاح النهائي يُحسم في GitHub Actions وتيليجرام عندك.

## قواعد الإخفاق والسلامة

- إذا تعذر تفريغ الصوت أو لم توجد كلمات متزامنة داخل المقطع، **لا يتم إرسال فيديو بلا كابشنز بصمت**؛ تظهر رسالة خطأ في تيليجرام.
- الكابشنز تعتمد على الكلام المنطوق، لا على العنوان أو وصف الفيديو. نموذج Groq يدعم توقيتات على مستوى الكلمة؛ مزود آخر قد يوفر توقيتات على مستوى المقاطع، وعند تقسيم المقاطع الطويلة قد تكون التوقيتات الداخلية تقريبية (يُذكر ذلك في سجل التشغيل).
- لا تغيير على منطق النشر؛ `/publish` يظل متوقفًا.
- بيانات التفريغ المؤقتة لا تضاف إلى متغير GitHub الخاص باقتراحات القص.
- لا ترفع مفاتيح API أو ملفات `.env` أو `cookies.txt`.
